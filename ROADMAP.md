# Slopless roadmap

This is the direction of the independently maintained Slopless project, not a promise of features or delivery dates.

## Available now

- Independent Slopless identity, static website, setup guide, and source/licensing page.
- Fifty visual materials and twenty-one example pages, with inherited catalog provenance documented in NOTICE.md.
- Slopless skill discovery, local installers, agent invocation, and opt-in edit-time hook.
- Static and optional browser design checks, plus existing-page before/kept comparisons.
- Copy-only project-state migration and explicit compatibility with older browser configuration and CSS stamps.
- Site-link, metadata, catalog, installation, migration, and browser regression checks.
- Free GitHub Pages hosting configuration and an optional Vercel static-site configuration.

## Next

- Add new original material systems and corresponding examples to extend the inherited catalog.
- Improve framework-specific examples for app screens, forms, and multi-page flows.
- Exercise real-agent end-to-end conformance separately from script and browser regression tests.
- Collect new reproducible evaluation results, clearly separating them from inherited research observations.

## Deliberate boundaries

- No invented client logos, usage counts, testimonials, model results, or paid-provider credits.
- No account, subscription, form backend, or deployment provider account hidden behind a working-looking button.
- No automatic removal of a user's existing skills, project state, or unrelated editor hooks.
- No paid API requests in verification or CI.
