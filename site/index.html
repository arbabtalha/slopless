02 / The practice

A little direction.
A much better result.

No new editor. No hosted account. Slopless works inside the coding agent you already use, with the code you already own.

01

Start with the job.

A booking page should book. A shop should sell. Your agent reads the project and asks for the real content before it designs a thing.

/slopless a page for my pottery studio
02

Pick a point of view.

Choose from three suggested materials, name one you like, or ask for a custom direction. The system sets the character, not the layout.

Use Kiln. Keep it tactile and quiet.
03

Check the actual page.

Static checks catch the familiar shortcuts. Optional browser checks examine contrast, focus, responsive layout, and the finished page.

/slopless audit ./index.html
S/

Already have a design? Nothing gets redesigned unless you ask. Keep the content and wiring; choose a polish, a restyle, or a full rebuild.

A few useful answers

Before you begin.

Is this a website builder?

Slopless is a skill your coding agent reads, not a hosted drag-and-drop builder. It provides design references, a workflow, and scripts. Your agent produces the code in your project.

Do I have to use a theme?

No. Ask for a custom direction. The accessibility and quality checks still apply, but the agent can build a visual system around your brief.

Does it cost anything?

The toolkit is free under the MIT license. Your coding agent subscription, optional image-generation API usage, and other services keep their own costs. Slopless does not collect a subscription.

Will it change my existing app?

Not automatically. Name the target explicitly with /slopless redesign <path>. Use audit for a report without changing the page.

What happens to my project data?

The website has no analytics, account system, or Slopless backend. Skill scripts run locally. Your agent uses its own provider; optional image generation and photo downloads contact their respective services. See the setup guide before enabling them.
