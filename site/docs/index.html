Slopless / Documentation

A little setup.
A lot more intention.

A practical guide to installing the toolkit, choosing a direction, and checking the page you actually made.

Quick start

You need Node.js 18 or later, Git, and a supported coding agent. Slopless is a local skill, not an npm-hosted website builder. It does not require a Slopless account.

$npx skills add arbabtalha/slopless -g

The global flag -g makes the skill available across projects. Leave it off for a project-local install. The installer prompts you to select your agents.

Choose your agent

AgentInvokeGlobal location
Claude Code/slopless~/.claude/skills/slopless
Codex$slopless~/.agents/skills/slopless
Cursor/sloplessDiscovers compatible skill locations
OpenCode/sloplessDiscovers compatible skill locations

Install for a specific agent with --agent claude-code, codex, cursor, or opencode. Restart the agent if the skill does not appear.

Install from a local checkout

git clone https://github.com/arbabtalha/slopless.git
cd slopless
node skills/slopless/scripts/install.mjs --claude --dry-run
node skills/slopless/scripts/install.mjs --claude

Use --codex, --cursor, or --opencode --copy for another agent. The local installer checks references and themes before copying. Existing Slopless copies are replaced when you explicitly install again; unrelated skills are not touched.

Claude Code plugin

/plugin marketplace add arbabtalha/slopless
/plugin install slopless@slopless
/slopless:slopless a page for my project

You can also point the marketplace command at the absolute path of your local checkout. The local skill installer above works if your agent does not support marketplaces.

Build a new page

/slopless a booking page for a small ceramics workshop
/slopless a pricing page for my developer tool, custom

Provide the actual product, content, photographs, and working destinations. Slopless asks the agent to read the project, suggest a material, build the hero, and check the finished page. It does not invent customer numbers or wire up a form to an imaginary backend.

Browse the material catalog to name a direction, or say custom to work without a catalog theme. A theme supplies a visual vocabulary, not a fixed page layout.

Redesign without losing the wiring

/slopless redesign ./src/app
/slopless redesign ./index.html, keep the layout
/slopless audit ./index.html

A full redesign changes the system and layout. Ask to keep the layout for a restyle, or ask for polish for a narrower pass. Audit is report-only. Before a redesign, the toolkit can record links, fields, headings, and handlers; its kept check detects omissions.

node skills/slopless/scripts/sloplint.mjs ./index.html --before
# Perform the requested redesign, then compare:
node skills/slopless/scripts/sloplint.mjs ./index.html --kept

Run the quality checks

Static checks need only Node.js. They inspect HTML, CSS, and common framework components. Browser checks also need Chrome or Chromium and Puppeteer.

node skills/slopless/scripts/sloplint.mjs ./index.html
node skills/slopless/scripts/sloplint.mjs ./src --json

# Optional, real-browser checks:
npm install -g puppeteer-core
node skills/slopless/scripts/sloplint.mjs ./index.html --render

Set CHROME_PATH if your browser is not in a standard location. SLOPLESS_PUPPETEER can point to a directory from which Node can resolve puppeteer-core. For example, use the project directory containing its node_modules, not the module entry file.

The edit-time Claude Code hook is opt-in:

node skills/slopless/scripts/install-hook.mjs --print
node skills/slopless/scripts/install-hook.mjs
node skills/slopless/scripts/install-hook.mjs --remove

The hook advises on edits; it is not a replacement for a final review. Browser measurements and automated lint do not guarantee a bug-free or accessible product.

Images, privacy & optional services

  • No provider key is needed to install or run static checks.
  • The local photo index lists openly licensed Wikimedia photographs. Photo downloads contact Wikimedia; individual attribution and license terms still apply.
  • Optional image generation contacts Together's API using your TOGETHER_API_KEY. Provider usage can cost money. It is not a Slopless sponsorship or included credit.
  • Your coding agent uses its own model provider and privacy policy. This website itself has no analytics, tracking cookies, forms, or backend.
  • Included demo pages may load fonts and photographs from third-party services. The Slopless homepage uses locally served fonts and screenshots.

Keep API keys in your environment or an ignored local environment file. Never put them in website JavaScript or commit them to Git.

Existing installations and project data

Slopless installs alongside the predecessor, without deleting its skill folders or changing your old agent configuration. New runs use .slopless/. To copy a project's legacy state safely:

node scripts/migrate.mjs --project /path/to/project --dry-run
node scripts/migrate.mjs --project /path/to/project

The migration copies missing files only. It leaves the source untouched, never overwrites existing destination files, and rejects symlinks. Older browser environment variable names and predecessor CSS stamps remain accepted for compatibility; newly generated output uses Slopless.

Old edit-time hooks remain separate. Review or remove them through the original installer if you no longer want both hooks. Do not delete an entire agent settings file.

A few common fixes

  • Skill not found: check the chosen agent, installation location, and restart its session. The skill frontmatter name is slopless.
  • No Chrome found: install a browser and set CHROME_PATH, or run static checks without --render.
  • No image API key: generation is optional. Use supplied photographs, real product screenshots, or a type-led design.
  • Plugin install fails: use the Git checkout installer and check your agent's marketplace support.
  • A demo font or image does not load: its external host may be blocked. The core toolkit and homepage still work without those hosts.

For a reproducible problem, open a GitHub issue with your Node version, agent, command, and redacted error output. Do not include API keys or private project content.
